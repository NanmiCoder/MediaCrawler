# Redis 缓存格式升级

RedisCache 现在仅保存 JSON 支持的基础值：字符串、数值、布尔值、null、列表和字符串键字典。
不再支持任意 Python 对象、bytes 或以 tuple 类型还原数据；调用方需要显式转换。
当前代理缓存传入 JSON 字符串，短信验证码传入字符串，均符合这一约定。

旧 pickle 数据与损坏 JSON 作为缓存未命中处理，不会尝试执行反序列化，也不会删除其他业务 key。
旧值在到期或重新写入后自然替换。升级时应一起重启使用本项目缓存的进程，避免新旧格式混用；
代理缓存可能出现一次冷启动。回退到旧版本会恢复 pickle 的安全风险，且旧版本无法读取新 JSON 值。
